# «Ковёр помнит»

Документальный motion-design ролик из фотографий, собранный на [Remotion](https://www.remotion.dev).
1920×1080, ~85 с, композиция `KoverPomnit`.

**Визуальный язык — борцовский ковёр:** синее поле, красное кольцо, жёлтый центр.
Круги ковра работают как переходы (iris), цветные плашки — как «бросок» между сценами,
слова выбиваются кинетической типографикой.

## Запуск

```bash
npm i
npm run dev                                   # Remotion Studio: превью и таймлайн
npx remotion render KoverPomnit out/kover-pomnit.mp4
```

## Сцены

| # | Сцена | Что происходит |
|---|---|---|
| 1 | Загадка | Кадр раскрывается из линии · «ЭТО Я.» + круг вокруг лица · счётчик 0→17 · пунктир вокруг размытого человека · синяя плашка «СЕМЬ ЛЕТ / ПЯТЬ ЛЕТ» · фото становится карточкой · перемотка ◀◀ 17→12 |
| 2 | 12 лет | Фото проявляется внутри цифр «12», камера пролетает сквозь цифру · переходы полосами · «И МЕНЯ САМОГО.» с ударной волной |
| 3 | Путь | 3D-коридор из фотокарточек · «ЗДЕСЬ» стоит, остальное меняется (анафора) · «И» въезжает перед «ЗДЕСЬ» · карточка переворачивается в настоящее |
| 4 | Сегодня | Счётчик 12→24 ▶▶ · список копится как лента · ковёр рисуется и уходит вдаль · круг закрывается в центр ковра |
| 5 | Раскрытие | Круг раскрывается · «СЧАСТЛИВЫХ» по буквам · blur снимается: силуэт → лицо → полностью · свет · плашки с именем |
| 6 | Чемпионат мира | Три колонки (Астана · арена · трибуны), арена раскрывается · счётчик 2026 · «БОЛЬШЕ,» растёт |
| 7 | Ковёр помнит | Сплит-экран · печатная машинка · стена воспоминаний и наезд в 12-летнего · фото сжимается в ковёр · тишина · хлопок · «КОВЁР ПОМНИТ.» |

## Что где менять

- **`src/config.ts`** — палитра, фото, длительность сцен, **весь текст** (`TEXT`), музыка и SFX.
- **`src/scenes/S*.tsx`** — хореография сцены: таблица `T` вверху файла — моменты
  появления слов и переходов в секундах от начала сцены.
- **`src/motion/`** — инструменты: кинетический текст (`Words`, `Letters`, `Slam`,
  `Odometer`, `Slot`, `Typewriter`), графика ковра (`Mat`, `Iris`, `Panels`, `Strips`,
  `Annotation`, `Shockwave`, `LightSweep`), фото (`Photo`, `MysteryLayer`).

Фото кладутся в `public/assets/photos/` (см. README там же). Нет фото — будет плейсхолдер.

## Звук

В `public/assets/audio/` — синтезированные заготовки: музыкальные подложки (сердцебиение,
атмосфера, зал, пэд, ритм «Пути», весёлый грув, трибуны) и SFX (whoosh, удары, riser,
тики счётчика, перемотка, переворот карточки, затвор, искры, маркер, хлопок по ковру).
Генератор: `node scripts/make-placeholder-audio.mjs`. Замените файлы своими (те же имена).

Закадровый голос: положите файл в `public/assets/audio/` и впишите имя в
`AUDIO.voiceover` (звучит с 0:00). Под голос убавьте `AUDIO.music` и `AUDIO.sfx`.
