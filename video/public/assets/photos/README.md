# Фотографии

Положите сюда фото с этими именами (`.jpg`, `.jpeg`, `.png` или `.webp`).
Если файла нет, в ролике на его месте появится плейсхолдер с подписью.

| Файл | Где в ролике |
|---|---|
| `01_fadzaev_photo` | Сцены 1, 5, 7: я (17 лет) рядом с Арсеном Фадзаевым |
| `02_age_12` | Сцена 2 (внутри цифр «12») и сцена 7 (наезд в финале) |
| `03_training_01` | Сцена 2: тренировка |
| `04_training_02` | Сцена 2: команда, тренеры |
| `05_competition` | Сцена 3 «учился побеждать», сцена 7 «соревнования» |
| `06_medal` | Сцена 3 «бороться до конца» |
| `07_youth` | Сцена 3 «учился проигрывать» |
| `08_age_24` | Сцена 4: я сейчас, 24 года |
| `09_astana` | Сцена 6: левая колонка — Астана сегодня |
| `10_arena` | Сцена 6: арена чемпионата мира |
| `11_crowd` | Сцена 6: правая колонка — трибуны |
| `12_mat` | Сцена 7: плитка в стене воспоминаний |

Если вы замените `01_fadzaev_photo`, поправьте в `src/config.ts` → `PHOTOS.fadzaev.mystery`:
какую часть кадра размывать до раскрытия (`from`/`to`) и где лица (`face`, `me`) — по ним рисуются круги-пометки.

Фотографии в git не попадают (`.gitignore`), потому что репозиторий публичный.
