# Фотографии

Положите сюда фото с этими именами (`.jpg`, `.jpeg`, `.png` или `.webp`).
Если файла нет, в ролике на его месте появится плейсхолдер с подписью.

| Файл | Где в ролике |
|---|---|
| `01_fadzaev_photo` | Сцены 1 и 5: я (17 лет) рядом с Арсеном Фадзаевым |
| `02_age_12` | Сцена 2: «Мне 12» |
| `03_training_01` | Сцена 2: тренировка, команда |
| `04_training_02` | Сцена 2: тренировка, тренеры |
| `05_competition` | Сцена 3: пьедестал — «учился побеждать» |
| `06_medal` | Сцена 3: медаль — «бороться до конца» |
| `07_youth` | Сцена 3: на ковре — «учился проигрывать» |
| `08_age_24` | Сцена 4: я сейчас, 24 года (выпускной) |
| `09_astana` | Сцена 6: Астана сегодня |
| `10_arena` | Сцена 6: арена чемпионата мира |
| `11_crowd` | Сцена 7: трибуны, болельщики |
| `12_mat` | Сцена 7: борцовский ковёр (последний кадр и фон финальной надписи) |

Если вы замените `01_fadzaev_photo`, поправьте в `src/config.ts` → `PHOTOS.fadzaev.mystery`,
какую часть кадра (по горизонтали) размывать до раскрытия.

Фотографии в git не попадают (`.gitignore`), потому что репозиторий публичный.
